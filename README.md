# 深圳职业技术大学《学生手册》智能问答

学生用大白话问一句（「挂科了怎么办」「宿舍能用吹风机吗」「班车怎么坐」），
系统**只依据《学生手册（2025 年修订）》原文**作答，每条结论都能点回它引用的那一条；
手册里没写的，先说「本手册中没有对应内容」，再去**学校官网**找一圈，找到就照抄原文并单独标来源。

> **完整文档**：[`docs/项目介绍与技术全流程.md`](docs/项目介绍与技术全流程.md)
> —— 项目解决什么现实问题、每项技术解决什么问题、从启动到出答案的每个环节、实测成绩。

---

## 一、解决的核心问题

《学生手册（2025 年修订）》正文 3.8 MB，**42 份制度文件、974 个条款**。学生想问
「旷课多少学时会被开除」，得先猜这条归哪个文件管，再在 PDF 里搜——搜不到不等于没有，
手册写「体质测试」，学生说的是「体测」。

直接问通用大模型呢？它会**编**——把不存在的条例说得像真的一样，或者把
「学生公寓大门 6:00–23:30」直接代成「图书馆开放时间」，还给你编个出处。

手册这类内容，答错一条就是误导学生。所以本项目只解决一件事：

> **宁可不答，也不许编。** 每条结论都要能点回原文；手册没有就明说没有；
> 官网查到的必须单独标来源、只照抄、不让模型转述。

## 二、技术栈一览

**界面**：Streamlit 单页应用（入口 `app.py`），打开网址即用，无需登录或口令，手机/电脑都能开

**大脑**：智谱 GLM-4-Flash（免费档），LangChain 编排，撞限速自动重试

**检索**：bge-m3 向量 + 自研 BM25（字符二元组）双路 → RRF 融合 → bge-reranker 精排
→ 父子扩展。编码与重排可选本机显卡或在线免费接口（Cloudflare Workers AI / 模力方舟 / 硅基流动），
三者同为 1024 维 bge-m3，**换后端不用重算向量**

**校正层（自研，不靠模型自觉）**
- 拒答前置：检索分太低直接判"没有"
- **主体一致闸**：问图书馆却一条图书馆都没检索到 → 判答非所问，不交给模型硬套
- 引用校验：逐条核对 `[E1]` 角标与原文，对不上就拒答
- 拒答复核：模型说"证据不足"但检索分够高 → 判误拒，重答一次
- 角标重排：按出现顺序编号，锚点带轮次前缀（否则第二轮点 E1 跳回第一轮）

**兜底层**
- **官网兜底**：手册判"没有"后去学校官网站内搜索，抓正文、抽 PDF 附件、
  识别表格，出 `W1/W2` 来源卡（蓝灰系，页头写明"不是学生手册"）
- **个人数据分流**：「我的绩点/学费/课表」→ 0 秒引导去统一身份认证平台，不检索
- **程序化兜底**：模型彻底挂了就照抄原文，并在页面明说"本次是兜底"

**存储**：SQLite 存条款；云库（Postgres + PostgREST）存留言墙与使用统计；
会话记忆只在浏览器里（`st.session_state`），刷新即清，不写云库

## 三、一次提问的流程

```
学生提问
   │
   ① 分流    是「我自己的数据」吗？→ 0 秒给登录引导，不检索
   │
   ② 规划    要不要拆题；是追问吗（只认"它/那/呢"这类承接词）；
   │         口语词换正名（体测→体质测试、吹风机→违章电器）
   │
   ③ 检索    向量 + BM25 双路 → RRF 融合 → 精排 → 前 6 条 + 邻条
   │         任何一路挂了只记一笔、跳过，不整题判死
   │
   ④ 两闸    拒答前置（< 0.03）→ 主体一致闸（< 0.20 且场所词占比不足两成）
   │
   ⑤ 生成    只拿原文条款作答，每句挂 [E1]
   │
   ⑥ 自检    证据不够再检索，最多 2 轮
   │
   ⑦ 校验    逐条核对角标与原文；误拒就带纠正提示重答
   │
   ⑧ 兜底    手册没有 → 官网搜索 → W1/W2 来源卡（原句 + 表格 + 链接）
   │
   ⑨ 出答案  结论 + 分点 + 原文卡片（可点跳转）+ 内部过程 + 日志
```

## 四、跑起来

```bash
pip install -r requirements-local.txt     # 本机跑用这份；线上用 requirements.txt
cp .env.example .env                       # 填密钥（真 .env 不进仓库）
双击「启动网页问答.bat」                    # 自动挑空闲端口，10 秒后开浏览器
# 或：python -m streamlit run app.py
```

线上推 `main` 后 Streamlit Cloud 自动重建（1~2 分钟），无需在 Cloud 侧点按钮。

> **编码后端**：仓库**不带**本地向量模型（bge-m3 权重 4 GB+，不宜进版本库）。
> 默认 `EMBED_BACKEND=api` 走在线接口，与线上完全一致；有显卡想跑本机，
> 自行下载模型到 `models/bge-m3/` 并把 `EMBED_BACKEND` 改成 `local`。
> 两条路的向量维度都是 1024，**换后端不用重算 `data/vectors.npy`**。

## 五、目录结构（要点）

```
app.py                 网页入口（页面、渲染、留言墙、看板）
src/core/              问答主链路：编排、规划、生成、自检、校验、兜底
src/retrieval/         检索与守卫：双路检索、BM25、口语词、主体闸、登录分流、官网兜底
src/infra/             配套设施：条款库、云库、日志、会话记忆、热重载
src/dev/build/         PDF → 条款 → 索引 → 向量（一次性构建）
src/dev/eval/          评测与对比
src/dev/diag/          诊断、探针、保活、截页
src/tests/             24 个回归测试（run_all.py 一把跑）
data/                  条款、索引、向量、评测集；历史实验归档在 data/eval_history/
docs/                  项目介绍与技术全流程、截图
```

## 六、验收

```bash
python src/tests/run_all.py                        # 24 个测试脚本
python src/dev/diag/probe_hard_cases.py            # 16 组刁钻问法
python src/dev/diag/probe_web.py                   # 官网兜底 20 题
python src/dev/diag/check_subject_guard.py         # 主体闸 7 拦 5 放 + 60 题零误拦
python src/dev/diag/check_followup_guard.py        # 换话题 / 真追问
```

出处命中率 1.000，误拒 0。
