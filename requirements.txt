# 这份清单**故意保持轻量**，三个原因：
#
#   1. 线上没有显卡、内存上限约 2.7 GB。本机那套 bge-m3 + bge-reranker-v2-m3
#      加起来 4.4 GB，根本放不下 —— 所以「每次提问现场算问题向量 + 重排」这两步
#      改成调在线接口（见 src/embed_api.py，模力方舟免费档提供同一对模型）。
#      注意：**文档侧**的向量库 data/vectors.npy 是离线算好的，照旧复用，不受影响。
#
#   2. 原来的 `torch==2.10.0+cu128` 在 Linux 上**装不上**：`+cu128` 是"本地版本
#      标签"，PyPI 不接受这种包名（CUDA 版 wheel 只放在 PyTorch 官方仓库）。
#      Streamlit Cloud 执行 pip install 时会直接报 "Could not find a version"，
#      整个部署红掉 —— 连页面都出不来。而且那边没显卡，装了也是白占 2 GB 磁盘。
#
#   3. PDF 解析（pymupdf / pdfplumber）只在**离线建库**时用得到，运行时不碰。
#
# 本机开发（要用本地大模型）请改装：pip install -r requirements-local.txt
# ============================================================================
